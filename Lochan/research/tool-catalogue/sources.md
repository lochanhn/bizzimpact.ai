# AI tool catalogue expansion — source register

November 7, 2026 · 100 additional products · 111 total catalogue entries

## Review method and limits

Official vendor product pages or help articles were retrieved, then selected page titles, description metadata and AI-related passages were reviewed. Four pricing pages received an additional selected-section review. This is product discovery research, not a full read of all vendor documentation, security assessment, usability test or endorsement. Numeric vendor performance claims were not adopted as independent results. No paid APIs, registrations, vendor-account tests or browser windows were used.

The website stores the reviewed records in [catalogue-expansion.json](../../../website/data/catalogue-expansion.json). Per-tool findings and small-business implications are in [research-notes.md](research-notes.md). [retrieval-audit.json](retrieval-audit.json) preserves attempted URLs, redirects, failed requests and successful fallback methods. Directly retrieved page hashes identify the bytes retrieved; they are not quality certifications. Full vendor HTML was kept only in temporary working storage, not committed here.

The original eleven tools retain their earlier sources. These 100 additions are distinct products; a rebrand is a single entry, not counted twice. Three additions have selected plan details; 97 remain product-level reviews. Existing software features are included where relevant, not counted as separate tools for every feature.
